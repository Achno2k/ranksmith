# Web Research

## Workflow

1. Define the question, audience, geography, freshness, and required output. Ask only when ambiguity changes the result.
2. Use a domain MCP first when it offers structured evidence; use Ahrefs for SEO data. Then search the web for context and confirmation. Use Playwright MCP as well if you want to run a headless chrome browser.
4. Research websites like Reddit and Quora and check for posts around this space to gather more content ideas.
5. Open source pages. Never treat search snippets as evidence.
6. Prefer primary, recent sources. Confirm consequential claims with a primary source or two independent sources when practical.
7. Record source, URL, publication or update date, and access date. For metrics, also record provider, database or geography, and retrieval date.
8. Separate facts, third-party estimates, and inference. Report conflicts and missing evidence. Never invent metrics, quotes, or citations.
9. Stop when additional sources no longer change the answer.

## Output

- Lead with the answer.
- Cite claims near the supporting text.
- Include a compact evidence table when comparing several findings.
- State uncertainty and gaps.
- Omit the research diary.
